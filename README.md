## Description:

<p align="center">
<img src="https://github.com/2024-1-MCC1/Projeto3/blob/73ab3e6ca10bf70795727eabff7e3570c12648a3/Imagens/Play.png" alt="Eco x Ego" border="0">
  Game Design by <a href= "https://www.linkedin.com/in/gabrielmarussi">Gabriel Marussi</a>
</p>

This project is a collaboration with FECAP, presented as an educational game developed on the Unity platform using C#. Its main goal is to promote a mindset shift aligned with the UN Sustainable Development Goals (SDGs), with special focus on goals 13, 14, and 15.
<br><br>
We aim to deliver an engaging experience that inspires players to reflect on key environmental issues and adopt more sustainable and responsible behaviors. Through meaningful narrative and interactions, this project contributes to awareness-building toward a fairer and more sustainable future.
<br><br>

## 🛠 Installation

<b>Windows:</b>

No installation is required. Just download the files and you will be able to play. Open the "<a href= "https://github.com/gabmarussi/Eco_x_Ego/tree/main/Eco%20x%20Ego%20(Final)/Executável">Executable</a>" folder and download it.<br>
Then run "<a href="https://github.com/gabmarussi/Eco_x_Ego/blob/main/Eco%20x%20Ego%20(Final)/Execut%C3%A1vel/Eco%20x%20Ego.exe">Eco x Ego.exe</a>" like any other program to start playing.

## 💻 Development Setup

To open this project, you need the following tools:

Download <a href="https://unity.com/download">Unity</a> and install <a href="https://unity.com/releases/editor/whats-new/2022.3.10">version 2022.3.10</a>.

Follow these steps:

```sh
- Install Unity.
- Use version 2022.3.10 (other versions may cause errors when opening the project).
- Download the folders: "Assets", "Packages", and "ProjectSettings".
- Place them in a single directory.
- Open that directory with Unity.
```

After that, you will be able to edit/play the project.
